## Goals

- Consume triple evaluator artifacts generated by `causal-app-facing-production-integration-ci-advisory-remediation-report-consumption-report-evaluation-report-evaluation-report-evaluation-report-evaluator`.
- Emit deterministic local JSON and text report artifacts.
- Classify report status as `ready`, `advisory`, or `blocked`.
- Carry forward request summaries, support evidence summaries, signal summaries, findings, checks, policy rule ids, consumption scope ids, denied claims, next queries, and agent guidance.
- Preserve the record-only, local-only, no-mutation authority boundary.
- Register the new schema in governance and production hardening backlog.
- Advance the roadmap to the four-level application-boundary branch.

## Non-Goals

- No app runtime integration.
- No GitHub API mutation, workflow mutation, step summary writing, pull request comments, required status checks, or CI enforcement.
- No artifact upload or public publication.
- No durable writes, NenDB writes, NenDB adapter execution, or Cockroach work.
- No raw prompt, raw response, or raw payload capture.
- No production telemetry ingestion, deployment claims, production health claims, hosted dashboards, auto-apply, or mutation authority.
- No renderer change; the human workbench remains SolidJS inside `webui-dev/zig-webui`.

## Report Rules

The report is `ready` when:

- Source schema and schema version match the triple evaluator schema.
- Source evaluator status is `ready`.
- `ready_for_next_branch` is true.
- Source blocked findings count is zero and no blocked finding is present.
- Source triple policy/application refs are present and ready/applied.
- Request and evidence summaries are present.
- Source checks, signals, denied claims, next queries, and guidance are present.
- Every authority flag remains disabled.
- Advisory/read-only/SolidJS workbench flags remain enabled.
- Publication channels remain local-only and non-mutating.

The report is `advisory` when source evaluator evidence is reportable and non-blocked, but source status or findings are advisory.

The report is `blocked` when source schema is unsupported, source is blocked, required source refs or summaries are missing, any blocked finding exists, authority drifts, SolidJS/read-only posture drifts, or local-only publication posture is violated.

## Outputs

JSON output should include:

- Schema metadata and branch handoff fields.
- Source evaluator path, schema, status, and ready flag.
- Triple policy/application refs and inherited source refs.
- Source request/support summaries and current request/support summaries.
- Source signals, checks, blocked findings, advisory findings, denied claims, policy rule ids, consumption scope ids, and next queries.
- Report checks, publication channels, required verification commands, and agent guidance.
- All authority flags and `mutation_authority = "none"`.

Text output should mirror the same information for human review.
