# ZigEffect Hero Slides Redesign

Date: 2026-07-12
Status: Approved by user selection of all three generated concepts

## Goal

Replace the existing Foundation / Runtime / Proof hero images with the three
selected concepts, in displayed order, as one coherent agentic development story.

## Selected slides

1. **Causal Repair Loop** — an agent asks why checkout failed, follows the typed
   execution trace to one failing boundary, applies a typed repair, replays the
   failure, and receives a complete verified receipt.
2. **Agent Microscope** — a causal timeline narrows request, scope, fiber, HTTP,
   SQL, and finalizer activity into the minimal root-cause path and repaired replay.
3. **Intent to Proof** — a requirement becomes a constrained Zig change, runtime
   evidence, Testing v2 proof, and a ready-to-ship outcome across Yachdee and Ziac.

## Copy contract

- Slide 1: `Agents don't guess. They repair from evidence.`
- Slide 2: `Ask the runtime why.`
- Slide 3: `From intent to proof.`

The body copy and notes explain the concrete mechanism shown in each image. Tabs
are named `Repair`, `Inspect`, and `Ship`. CTAs link to the causal graph, runtime,
testing, How It Works, and Built With pages.

## Asset contract

- Create three dedicated 1536 × 1024 landscape infographic assets from the selected
  full-page references.
- Each asset contains only the right-side technical story; no header, hero headline,
  CTA, carousel controls, or duplicated site chrome.
- Use warm white, slate, hairline gray, Zig orange, and restrained green verification.
- Keep labels large enough for a 760 × 560 desktop slot and a contained mobile slot.
- Do not use robots, brains, sparkles, people, glossy 3D, purple, neon, or generic
  feature-icon grids.

## Interaction contract

- Preserve autoplay, pause/play, previous/next, direct tab selection, arrow-key
  navigation, polite announcements, visible progress, and reduced-motion behavior.
- Direct interaction pauses autoplay.
- Images remain fully contained and uncropped at desktop and mobile breakpoints.

## Acceptance criteria

- The three selected concepts appear in the selected order with matching copy.
- Old `foundation-plane.png`, `agent-runtime.png`, and `production-proof.png` are no
  longer referenced by the carousel.
- All CTAs resolve to real site routes.
- The focused carousel tests, typecheck, production build, browser interactions,
  console check, and visual comparison pass.
