# Google Cloud Product Icons

These SVG and PNG files are unmodified 512 x 512 assets from the official Google Cloud icon
library: <https://cloud.google.com/icons>.

- Core product archive:
  `https://services.google.com/fh/files/misc/core-products-icons.zip`
- Product category archive:
  `https://services.google.com/fh/files/misc/category-icons.zip`
- Retrieved: 2026-07-11

The catalogue intentionally uses a category icon when the official core-product
archive does not contain a dedicated icon for a provider primitive. Non-GCP
resources must not use these marks.
