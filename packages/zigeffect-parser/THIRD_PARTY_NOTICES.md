# Third-party notices

## tree-sitter

This package vendors and statically links the MIT-licensed
[`tree-sitter/tree-sitter`](https://github.com/tree-sitter/tree-sitter) C
runtime pinned to tag `v0.25.10`, commit
`208c6cac1453315e979f05ab34b6d4f7cd0340be`.

## tree-sitter-typescript

This package compiles generated TypeScript and TSX grammar C sources from the
MIT-licensed
[`tree-sitter/tree-sitter-typescript`](https://github.com/tree-sitter/tree-sitter-typescript)
tag `v0.23.2`, commit `f975a621f4e7f532fe322e13c4f79495e0a7b2e7`.

The runtime and grammar licenses, exact source identities, and SHA-256
checksums are under `vendor/tree-sitter-runtime/` and
`vendor/tree-sitter-typescript/`.
